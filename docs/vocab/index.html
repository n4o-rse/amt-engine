Academic Meta Tool Vocabulary

The terms of the Academic Meta Tool (AMT): the classes and properties for modelling relations that hold only to a degree, the axioms that derive new relations from existing ones, and the fuzzy logics that combine their weights.

amt:InverseAxiom · http://academic-meta-tool.xyz/vocab#InverseAxiom

Asserts that two roles are inverses of each other.

Note. Reasoning rule: if edge (a -antecedent-> b) exists with weight w, infer (b -inverse-> a) with weight w.

Subclass of

Role Chain Axiom

amt:RoleChainAxiom · http://academic-meta-tool.xyz/vocab#RoleChainAxiom

Asserts that a chain of roles implies a consequent role; supports both legacy 2-ary form (antecedent1/antecedent2) and n-ary form (antecedents as RDF list).

Note. Reasoning rule: if edges (a -r1-> b) and (b -r2-> c) exist with weights w1 and w2, infer (a -consequent-> c) with weight = logic(w1, w2). Generalises to n antecedents.

Subclass of
amt:InferenceAxiom

Subsumption Axiomadded since 2018

amt:SubsumptionAxiom · http://academic-meta-tool.xyz/vocab#SubsumptionAxiom

Asserts that one role is finer than another: every edge carrying the sub-role also carries the super-role, at no lower weight. A statement about roles, not about any pair of nodes.

Note. Two readings. Entailment: if edge (a -subRole-> b) exists with weight w, infer (a -superRole-> b) with weight w. Redundancy elimination: if both (a -subRole-> b, w1) and (a -superRole-> b, w2) exist with w1 >= w2, the super-role edge is implied and may be suppressed. An implementation must offer entailment as its default and elimination as an option, because a consumer that does not know the role hierarchy needs every edge spelled out.

Subclass of
amt:InferenceAxiom

Disjoint Axiom

amt:DisjointAxiom · http://academic-meta-tool.xyz/vocab#DisjointAxiom

amt:SelfDisjointAxiom · http://academic-meta-tool.xyz/vocab#SelfDisjointAxiom

Fuzzy logics

An axiom names one of these operators in amt:logic. The operator combines the weights of the edges along a chain into the weight of the inferred edge.

OperatorFormulaArityBehaviour and use
Einstein productadded since 2018
amt:EinsteinProduct		(x * y) / (2 - (x + y - x * y))binarySoft multiplication, lying between Gödel and Product. Stricter than Gödel, gentler than Product. Automatically generated mappings of medium confidence. Good middle ground for n=3 and n=4.
Geometric meanadded since 2018
amt:GeometricMean		(x_1 * x_2 * ... * x_n)^(1/n)n-aryAggregation operator: n-th root of the product. Path-length neutral; expresses average link quality. Comparing inferences across different chain lengths. Recommended default for n >= 4. Note: not a t-norm in the strict sense.
Gödel logic
amt:GoedelLogic		min(x, y)binaryBottleneck semantics: the chain is as strong as its weakest link. Path length is ignored. Curated mappings; chains where path length should not penalise the result. Good default for n=2 and n=3.
Hamacher productadded since 2018
amt:HamacherProduct		(x * y) / (gamma + (1 - gamma) * (x + y - x * y))binaryParametrised t-norm family. Sensitivity to path length is controlled by a gamma parameter. Research applications where path-length sensitivity should be tuned empirically. gamma = 1 equals Product; gamma < 1 stricter; gamma > 1 softer.
Łukasiewicz logic
amt:LukasiewiczLogic		max(x + y - 1, 0)binaryBounded sum: max(x + y - 1, 0). Hard cutoff that collapses long chains to 0. Strict reasoning at n=2. Practically unusable for n >= 4 because the result almost always becomes 0.
Product logic
amt:ProductLogic		x * ybinaryProbabilistic conjunction: weights multiply along the chain. Penalises path length exponentially. Independent-evidence semantics. Best for n=2; can be too aggressive for chains with n >= 4.

Reasoning rules

RDFS cannot express arithmetic, so what a reasoner must do is described as data: each rule names the axiom it belongs to, when it applies and what it adds or reports. An implementation in another language can be derived from this list.

Disjoint Consistency Ruleadded since 2018

amt:DisjointRule · http://academic-meta-tool.xyz/vocab#DisjointRule
Applies to
amt:DisjointAxiom
Precondition
There exist edges (a -role1-> b) and (a -role2-> b) with weights > 0.
Effect
Report a consistency violation. Both edges contradict the disjointness assertion.

Inverse Inference Ruleadded since 2018

amt:InverseRule · http://academic-meta-tool.xyz/vocab#InverseRule
Applies to
amt:InverseAxiom
Precondition
There exists an edge (a -antecedent-> b) with weight w.
Effect
Add an edge (b -inverse-> a) with weight w. Mark the edge as inferred. Iterate to fixpoint.

Role Chain Inference Ruleadded since 2018

amt:RoleChainRule · http://academic-meta-tool.xyz/vocab#RoleChainRule
Applies to
amt:RoleChainAxiom
Precondition
There exists a sequence of edges e_1, ..., e_n such that e_i has role antecedents[i] and the target of e_i equals the source of e_{i+1}.
Effect
Add a new edge from source of e_1 to target of e_n with role = consequent and weight = logic(weight(e_1), ..., weight(e_n)). Mark the edge as inferred. Iterate to fixpoint.

Self-Disjoint Consistency Ruleadded since 2018

amt:SelfDisjointRule · http://academic-meta-tool.xyz/vocab#SelfDisjointRule
Applies to
amt:SelfDisjointAxiom
Precondition
There exists an edge (a -role-> a) with weight > 0.
Effect
Report a consistency violation. The role is asserted to be irreflexive.

Subsumption Inference Ruleadded since 2018

amt:SubsumptionRule · http://academic-meta-tool.xyz/vocab#SubsumptionRule
Applies to
amt:SubsumptionAxiom
Precondition
There exists an edge (a -subRole-> b) with weight w.
Effect
Default (entailment) mode: add an edge (a -superRole-> b) with weight w. Mark the edge as inferred. Iterate to fixpoint. Minimal mode: apply no entailment, and after the fixpoint suppress every inferred edge (a -superRole-> b, w2) for which an edge (a -subRole-> b, w1) with w1 >= w2 exists. Never suppress an asserted edge; when w1 < w2 keep both, because a coarse relation derived along a strong path can be worth more than a fine relation derived along a weak one.

Changes since 2018

The 2018 vocabulary ("Penny Edition") had 25 terms. All of them are still here with the same identifiers; nothing was removed or renamed. What changed:

  • 21 new terms, marked on their cards: DisjointRule, EinsteinProduct, GeometricMean, HamacherProduct, InverseRule, ReasoningRule, RoleChainRule, SelfDisjointRule, SubsumptionAxiom, SubsumptionRule, antecedents, appliesTo, arity, effect, formula, isParametrised, logicParameter, precondition, recommendedFor, subRole, superRole.
  • The fuzzy operators are instances of amt:Logic with a formula, an arity and a usage hint. In the 2018 RDF file they were modelled as classes.
  • Terms are typed as rdfs:Class and rdf:Property only. The 2018 RDF/XML also typed them as owl:Class, owl:ObjectProperty and owl:DatatypeProperty.
  • The ontology resource is http://academic-meta-tool.xyz/vocab (without the hash).
