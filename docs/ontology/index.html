The AMT data model

An AMT file describes a graph whose edges hold only to a degree. This page shows how such a file is put together: the building blocks, the axioms that derive new edges, and a small Turtle example for each. Every example on this page is parsed and validated against the SHACL shapes whenever the test suite runs.

All examples assume these prefixes. ex: stands for your own data.

@prefix amt:  <http://academic-meta-tool.xyz/vocab#> .
@prefix rdf:  <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .
@prefix xsd:  <http://www.w3.org/2001/XMLSchema#> .
@prefix ex:   <http://example.org/> .

Concepts and individuals

A Concept is a class of things in your domain, such as Person or Place. Individuals are linked to their Concept with amt:instanceOf. The optional amt:placeholder tells an editor what a label should look like.

ex:Person a amt:Concept ;
    rdfs:label "Person" ;
    amt:placeholder "Surname, forename" .

ex:ada amt:instanceOf ex:Person ;
    rdfs:label "Ada Lovelace" .

ex:charles amt:instanceOf ex:Person ;
    rdfs:label "Charles Babbage" .

Roles

A Role is a typed relation between two Concepts, the label of an edge. It declares its domain and range.

ex:connectedWith a amt:Role ;
    rdfs:label  "is connected with" ;
    rdfs:domain ex:Person ;
    rdfs:range  ex:Person .

Weighted edges

An edge is a quadruple: a subject, a role, an object and a weight between 0 and 1 in amt:weight. It is written as a reified statement, so that the weight has something to attach to.

[] rdf:subject   ex:ada ;
   rdf:predicate ex:connectedWith ;
   rdf:object    ex:charles ;
   amt:weight    "0.8"^^xsd:decimal .

Axioms

Axioms are statements about roles, not about individuals. Inference axioms derive new edges, integrity axioms describe edges that must not exist.

Role chain axiom

If a chain of edges exists, an edge between its two ends is inferred. Its weight is computed from the weights along the chain by the fuzzy logic named in amt:logic. amt:antecedents takes a list of any length; the older two-step form with amt:antecedent1 and amt:antecedent2 is still valid.

ex:RCA a amt:RoleChainAxiom ;
    amt:antecedents ( ex:connectedWith ex:connectedWith ) ;
    amt:consequent  ex:connectedWith ;
    amt:logic       amt:ProductLogic .
ex:RCA2 a amt:RoleChainAxiom ;
    amt:antecedent1 ex:connectedWith ;
    amt:antecedent2 ex:connectedWith ;
    amt:consequent  ex:connectedWith ;
    amt:logic       amt:GoedelLogic .

Parametrised operators take their parameter from amt:logicParameter:

ex:RCA3 a amt:RoleChainAxiom ;
    amt:antecedents ( ex:connectedWith ex:connectedWith ) ;
    amt:consequent  ex:connectedWith ;
    amt:logic       amt:HamacherProduct ;
    amt:logicParameter "0.5"^^xsd:decimal .

Inverse axiom

An edge with the antecedent role implies the reverse edge with the inverse role, at the same weight.

ex:interestOf a amt:Role ;
    rdfs:label  "is interest of" ;
    rdfs:domain ex:Person ;
    rdfs:range  ex:Person .

ex:hasInterest a amt:Role ;
    rdfs:label  "has interest" ;
    rdfs:domain ex:Person ;
    rdfs:range  ex:Person .

ex:IA a amt:InverseAxiom ;
    amt:antecedent ex:interestOf ;
    amt:inverse    ex:hasInterest .

Subsumption axiom

One role is finer than another: every edge with the sub-role is also an edge with the super-role, at the same weight. Only the direct step is declared; the engine computes the transitive closure.

ex:before a amt:Role ;
    rdfs:label  "before" ;
    rdfs:domain ex:Person ;
    rdfs:range  ex:Person .

ex:older a amt:Role ;
    rdfs:label  "older" ;
    rdfs:domain ex:Person ;
    rdfs:range  ex:Person .

ex:SUB a amt:SubsumptionAxiom ;
    amt:subRole   ex:before ;
    amt:superRole ex:older .

Disjoint axiom

Two roles must not hold between the same pair of nodes. The engine reports a violation if they do.

ex:friendOf a amt:Role ;
    rdfs:label  "friend of" ;
    rdfs:domain ex:Person ;
    rdfs:range  ex:Person .

ex:enemyOf a amt:Role ;
    rdfs:label  "enemy of" ;
    rdfs:domain ex:Person ;
    rdfs:range  ex:Person .

ex:DA a amt:DisjointAxiom ;
    amt:role1 ex:friendOf ;
    amt:role2 ex:enemyOf .

Self-disjoint axiom

A role must not hold between a node and itself.

ex:SDA a amt:SelfDisjointAxiom ;
    amt:role ex:enemyOf .

Fuzzy logics

The operators below combine the weights along a chain. Which one fits depends on how you want the length of a chain to count; the vocabulary page has a usage hint for each.

OperatorFormulaArity
amt:EinsteinProduct(x * y) / (2 - (x + y - x * y))binary
amt:GeometricMean(x_1 * x_2 * ... * x_n)^(1/n)n-ary
amt:GoedelLogicmin(x, y)binary
amt:HamacherProduct(x * y) / (gamma + (1 - gamma) * (x + y - x * y))binary
amt:LukasiewiczLogicmax(x + y - 1, 0)binary
amt:ProductLogicx * ybinary

Checking a file

The shapes in ontology/amt-shapes.ttl check that weights lie in [0, 1], that axioms have the properties they need and that role chains do not mix the two forms. The AMT engine runs them before it loads a file.
