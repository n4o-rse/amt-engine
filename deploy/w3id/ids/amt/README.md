## Academic Meta Tool (AMT)

Repository created to store the redirections for the Academic Meta Tool: the vocabulary (with content negotiation), the Explorer, the data model page and the software repositories. The pages are hosted on GitHub Pages of the alpaca-fair-framework organisation. The namespace of the vocabulary itself is http://academic-meta-tool.xyz/vocab# and does not change.
